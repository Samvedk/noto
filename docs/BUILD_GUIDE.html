SECTION 2: HARDWARE ASSEMBLY (VERY DETAILED)

1

Brain to Board

Click the CM3 Brain Chip into the long white connectors on the IO Board. Press both sides firmly until it "clicks".

2

Screen Ribbon

Flip up the black tab on the "DSI 0" port. Slide the ribbon in (Blue side UP) and lock the tab back down.

3

Battery Logic

Solder the Red wire to B+ and the Black wire to B- on the charger. Keep bare wires insulated with tape.

SAFETY WARNING: Never let exposed Red and Black wires touch. Tape them immediately with electrical (Kapton) tape.

SECTION 3: FIRST BOOT (SYSTEM SETUP)

1. Flash the OS to your eMMC using Balena Etcher.
2. Insert power via USB-C. Login: root, Pass: 1234.
3. Update the system soul:

sudo apt update && sudo apt upgrade -y
✅ If you see the Armbian logo on the screen, your boot is successful.

SECTION 4: RUNNING THE APP (KIOSK MODE)

Goal: Automate the Noto Web Engine boot sequence.

git clone https://github.com/Samvedk/noto.git /home/noto/app

Set the autostart in ~/.config/openbox/autostart:

chromium-browser --kiosk --no-sandbox file:///home/noto/app/welcome.html

SECTION 5: TOUCH + STYLUS OPTIMIZATION

1. AI Smoothing: Activate the RK3566 AI core brain:

sudo apt install -y rknn-toolkit2 rknn-rt

2. Instant Response: Set the touch polling to 400Hz in the system HUD settings.

SECTION 6: POWER OPTIMIZATION

1. Sleep Mode: Enable Deep Sleep for 12+ hour endurace.
2. 省電 (Power Save): Set CPU governor mode:

echo powersave | sudo tee /sys/devices/system/cpu/cpu0/cpufreq/scaling_governor

SECTION 7: FINAL INTEGRATION (CLEAN SETUP)

1. The Spine: Screw the board to a clear acrylic base using M2.5 nylon standoffs.
2. Tape: Tape the battery flat against the screen's back using Kapton tape.
