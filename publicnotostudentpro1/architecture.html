Section 02

IndexedDB Schema

All data is persisted locally via NotoDB_v2. Each collection maps to a key in the object store. No cloud. No localStorage for large payloads.

Store KeyTypeDescriptionMax Size
noto_gradesArray<Grade>List of all grades (id, name, emoji, createdAt)~1 KB
noto_subjects_{gradeId}Array<Subject>Subjects per grade (id, name, color, icon)~10 KB
noto_notebooks_{subjectId}Array<Notebook>Notebooks per subject (id, name, pageCount, lastEdited)~50 KB
noto_pages_{notebookId}Object<pgNum, PageData>All pages in a notebook. Each page has strokes[], stamps[], type, bmLabel~1 GB
noto_settingsObjectGlobal settings: theme, handedness, defaultPenSize, defaultPageType…~2 KB
noto_focus_logArray<Session>Deep Work session logs for XP/streak calculation~100 KB

Section 03

Page Data Structure

Each page is a plain JS object. Strokes are the core — every ink mark, shape, or text block is a stroke record.

// PageData object (one entry per page number)
{
  "type": "lined",         // lined | graph | blank | dotted | cornell | title
  "bmLabel": null,        // string if bookmarked, null otherwise
  "stamps": [            // draggable date stamps
    { "id": "ds_1234", "date": "2 May 2026", "label": "Exam", "x": 40, "y": 40 }
  ],
  "strokes": [           // all ink, shapes, text — in draw order

    // Ink stroke
    {
      "tool": "pen",        // pen | pencil | highlight | fountain
      "color": "#000000",
      "size": 3,
      "alpha": 1,
      "composite": "source-over",  // "multiply" for highlighter
      "path": [
        { "x": 120, "y": 84, "pressure": 0.6, "w": 3.2 }  // w = computed width
      ]
    },

    // Shape stroke
    {
      "type": "shape",
      "shape": "rect",      // rect | square | circle | triangle | line | arrow
      "x1": 50, "y1": 60, "x2": 200, "y2": 150,
      "color": "#2980b9", "size": 3, "filled": false
    },

    // Text stroke (committed text box)
    {
      "type": "text",
      "text": "Hello World\nLine 2",
      "x": 100, "y": 200,
      "color": "#000", "fontSize": 24
    }
  ]
}
Section 04

Canvas Layer Stack

The drawing surface is composed of four stacked canvases. This separation avoids expensive full-redraws during live drawing and enables GPU compositing.

z:6

actC — Active Canvas

Live stroke rendering during pointer movement via RAF loop. Cleared on stroke finalise.

z:5

dwC — Drawing Canvas

All committed strokes. New strokes are painted incrementally (no full redraw). Rebuilt only on undo/redo/page change.

z:2

bgC — Background Canvas

Page rule lines (lined/graph/dotted/cornell). Redrawn only on page type change.

mem

memC — Memory Canvas (off-screen)

Scratch buffer for overlay compositing (highlighter multiply blend). Never shown directly.

Section 05

Rendering Pipeline

The hot path for each ink stroke goes through two phases: live rendering during the gesture, and incremental commit at lift-off.

// PHASE 1 — Live (pointerdown → pointermove)
pointerdown  →  push to pendingPoints[]
RAF loop     →  actCtx.clearRect() + redraw currentPath on actC
               (variable-width Catmull-Rom spline per segment)

// PHASE 2 — Commit (pointerup / pointercancel)
finalise()   →  cancelAnimationFrame(rafId)
             →  actCtx.clearRect()            // wipe live layer
             →  drawStroke(stroke) on dwC     // paint ONLY this stroke (fast)
             →  push to pgData[page].strokes
             →  trigSave() → IndexedDB write (debounced 800 ms)

// UNDO / REDO / PAGE CHANGE
redraw()     →  ctx.clearRect() + forEach drawStroke()  // full rebuild

Section 07

Autosave & Sync Flow

User draws stroke
→
trigSave() called
→
Debounce 800 ms
→
notoSavePages(nbId, pgData)
→
IndexedDB write
→
saveDot → green

A 30-second interval also fires trigSave() as a safety net. On page exit, saveExit() performs a synchronous final write before navigating away.

Section 08

Palm Rejection Logic

// pointerdown on dwC
if (e.pointerType === 'pen') {
  activePointerType = 'pen';
  lastPenTime = Date.now();       // stamp pen contact
} else if (e.pointerType === 'touch') {
  if (activePointerType === 'pen' && elapsed < 5000) return; // pen recently active → ignore touch
  if (e.width > 20 || e.height > 20) return;           // large contact = palm → reject
  if (!e.isPrimary) return;                              // secondary finger → reject
}

// Focus mode: double-tap stylus to exit
if (e.pointerType === 'pen' && body.classList.contains('focus')) {
  if (timeSinceLast < 380 && distFromLast < 44) {
    body.classList.remove('focus'); return;   // exit, block drawing
  }
  recordTap();
}
